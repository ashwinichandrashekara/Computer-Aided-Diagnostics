# Computer Aided Diagnostics 

A comprehensive collection of Computer Aided Diagnostics (CAD) projects focusing
on medical image analysis, disease detection, and classification using traditional
and deep learning approaches.

## Project Overview

This repository implements traditional Computer Aided Diagnostic pipelines
for medical image analysis. The primary focus is on skin cancer classification
using both binary and multi-class approaches.

## What is Computer Aided Diagnostics?

Computer Aided Diagnostics (CAD) is a technology that assists medical
professionals in interpreting medical images by:

- **Detecting** abnormalities in medical images
- **Classifying** diseases based on visual patterns
- **Segmenting** regions of interest in medical scans
- **Reducing** human error in diagnosis
- **Improving** diagnostic accuracy and efficiency
